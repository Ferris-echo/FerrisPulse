# ATK V75X 灯光控制

## 使用

打开此本地适配版，选择ATK V75X，在“机械键盘硬件状态与控制台”点击“灯光控制”。首次打开读取当前配置，修改后点击“应用并校验”；不会随拖动、切换选项或电池轮询反复写Flash。建议关闭官方HUB页面，避免两个程序同时修改配置。

- 总开关；亮度五档（0/25/50/75/100%）。
- 官方20项灯效，包括常亮、呼吸、彩虹流动等；“自定义”只调用已有键盘方案，不包含逐键绘制。
- 支持的灯效可选择RGB单色或多彩/彩虹；不支持颜色的固定灯效自动禁用颜色项。
- 支持的动态灯效可选五档速度；常亮等无速度参数的模式自动禁用速度项。
- 模式20“全灭”独立于总开关；若希望亮起，请同时打开总开关并选择常亮等非全灭模式，亮度设为非零。

只开放已实测的 **ATK V75X 2.4G接收器320F:5088**；没有把共享PID视为任意ATK V75型号通用支持。有线5055、蓝牙以及其他V75系列固件尚未实测。

## 协议与安全

来源为[ATK官方旧版HUB](https://v2-hub.atk.pro/)，2026-10-22核对其EvisionApi和V75X配置页。仅提取协议事实，不引入或运行其驱动代码、依赖或固件。

- HID厂商集合UsagePage FF1C / Usage 0092，Input/Output均64字节，不操作受Windows保护的标准键盘集合。
- Windows报文：`04 SeqLo SeqHi CMD Count OffsetLo OffsetHi 00 Data...`，不足64字节补零。序号非零递增，CMD05读配置，CMD06写配置；应答匹配Report、序号、命令、数量、偏移和状态。
- 配置56字节，三块偏移0/24/48、数量24/24/8。**写首块会擦除同页其余字节；必须完整写回三块**，包括未改动的后续字段。不能只写首块或只写变化块。
- 字段：[1]模式1..20，[2]亮度0..4，[3]原始速度0..4（界面速度0..4映射4-raw），[5]00单色/FF多彩，[6..8]RGB，[28]00总开关启用/01关闭。
- 每次应用读取最新配置，仅修改以上白名单字段；不支持的字段保留原值，按键映射、休眠、Win锁、回报率与保留字节不改变。保留全部原始56字节，不采用官方页面重新组装时可能清零保留字段的做法。
- 电量与灯光共享通信锁和序号。只在原物理路径、原配置档仍一致时写入。应用后完整回读；部分失败时完整恢复原快照并回读。若中途断电或拔出，软件无法保证恢复，会明确告警；操作期间不要断开键盘或接收器。

## 验证边界

- 实机写入并回读：模式6常亮、亮度1（25%）、RGB64/128/192、总开关关闭、模式5呼吸、多彩FF、速度原始值0（界面最快）。动态速度参数在总开关关闭时测试，避免快速闪烁。
- 完成后恢复测试前模式20、亮度2、原始速度3、单色RGB255/129/155与总开关0；56字节逐字节一致。
- 实测指协议回读一致，不代表已逐项人工观察20种灯效。UI覆盖所有官方V75X模式；无逐键RGB编辑、音乐联动、侧灯或屏幕控制。
- 自动化覆盖报文边界、过期/错误应答、无关字段保留、能力表、无变化不写Flash、部分写失败与回读不符时恢复、恢复失败告警，以及UI选项、设备切换与重复DPI布局。
