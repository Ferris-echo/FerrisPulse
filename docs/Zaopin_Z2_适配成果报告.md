# 灵脉设备适配成果报告 · Zaopin Z2 (皂品 Z2)

**适配包**：`Zaopin_Z2.fp-adapter.json`（FDAS v2.0，Priority 200）
**硬件指纹**：VID `0x3554` / PID `0xF527`（4K 底座接收器，NORDIC nRF52810）· 2.4G 无线 · 17/17 字节私有端点
**协议族**：CompX / Beken `0x08` 帧 · `0x55` 互补校验

---

## 1. 结论

| 能力 | 状态 | 依据 |
|---|---|---|
| 电量 / 充电 | ✅ 已还原 | `rx[6]` = 0~100，`rx[7]==1` 充电，`rx[8..9]` = mV（大端） |
| DPI（50~26000，步进 50） | ✅ 已还原 | 编码 `dpi/50-1`，双字节 + flags + 数据字校验，落盘命令 `0x08` 写 `0x0C+4*stage` |
| 6 档位切换 | ✅ 已还原 | 地址 `0x04`，载荷 `{stage0, 0x55-stage0}` |
| 回报率 125/250/500/1000/2000/4000 | ✅ 已还原 | 地址 `0x00`，编码 `08/04/02/01/10/20`，上限 4000Hz |
| 自定义动作（灯效等） | ⛔ 未声明 | 该机型无灯效通道，不臆造写指令 |

**端点裁决**：探针列出 9 个端点，仅 `UsagePage 0xFF02 / Usage 0x0002 / 17↔17 / FeatureLen=0` 命中 CompX 私有控制通道（端点 3）。端点 1/2/8/9 为系统标准集合（鼠标/键盘/消费类），端点 4（`0xFF04` Feature 8B）、5/7（`0xFF05`/`0xFF03` 8B 单向）、6（`0xFF06` 49B）为固件升级或厂商调试通道，**未写入**。

## 2. 报文结构（17 字节，Report ID `0x08`）

| 偏移 | 含义 |
|---|---|
| 0 | Report ID `0x08` |
| 1 | 命令：`0x07` 写配置 / `0x08` 写落盘 / `0x04` 读电量 |
| 2 | 保留 `0x00` |
| 3–4 | 16 位地址（大端） |
| 5 | 数据长度 |
| 6–14 | 数据区（≤9 字节） |
| 15 | 保留 `0x00` |
| 16 | 校验：`(0x55 - sum(b[0..15])) & 0xFF` |

**地址表**：`0x0000` 回报率 · `0x0004` 激活档位 · `0x000C + 4*i` 第 i 档 DPI。

**DPI 数据字**（4 字节）：`{low, low, flags, ck}`，其中
`enc = dpi/50 - 1`、`low = enc & 0xFF`、`high = (enc>>8) & 0x03`、`flags = (high<<2)|(high<<6)`、`ck = (0x55 - low - low - flags) & 0xFF`。
X/Y 共用同一值（硬件不支持 XY 独立）。

## 3. 展开验证（本地仿真引擎逐帧回放，全部通过）

```
电量查询            08 04 00 00 00 00 00 00 00 00 00 00 00 00 00 00 49
回报率 1000Hz       08 07 00 00 00 02 01 54 00 00 00 00 00 00 00 00 EF
回报率 4000Hz       08 07 00 00 00 02 20 35 00 00 00 00 00 00 00 00 EF
激活第 3 档          08 07 00 00 04 02 02 53 00 00 00 00 00 00 00 00 EB
写第 3 档 1600DPI    08 08 00 00 14 04 1F 1F 00 17 00 00 00 00 00 00 D8
写第 2 档 26000DPI   08 08 00 00 10 04 07 07 88 BF 00 00 00 00 00 00 DC
```

样本帧 `08 04 00 00 00 02 2E 00 0F 12 ... F8` 回放结果：电量 46%、未充电、3858 mV、校验通过。

> 不变式：`code + parity ≡ 0x55`、`stage0 + stage0Parity ≡ 0x55`，故同一类帧的尾校验字节恒定（回报率恒 `EF`、激活恒 `EB`），可作为抓包时的快速自检特征。

## 4. 安全声明

- 全程**未向真机下发任何写指令**，无砖机风险。
- 协议来源为 FerrisPulse 开源仓库 `src/Hardware/VgnDeviceHelper.cs`（该文件已内置 `0xF527 → Zaopin Z2` 的显式分支与 4000Hz 上限），属"官方源码逆向"，非盲猜。
- 未对 `0xFF04` / `0xFF05` / `0xFF06` / `0xFF03` 等未知通道发送任何 Feature 写。

## 5. 已知边界（诚实缺口）

1. **电量算法**：固件库仑计在中间区间长时间停滞（实测 50% 卡 100 分钟）。官方驱动走电压查表法（并扣除 ~12mV 负载压降）。FDAS 表达式引擎无查表能力，本包用 `DirectPercent` 读 `rx[6]`；若需与官方显示对齐，需改用 `.fp-driver.cs` 实现 `VoltageToPercent` 曲线。
2. **有线 PID 未知**：现场仅暴露 `0xF527`。`devices` 矩阵已附 `0xF526`（Nano 1K 接收器）。插线后若出现新 PID，追加一行即可。
3. **8000Hz**：`EncodeVgnPollingRate` 无 8000 分支，Z2 4K 版硬件上限 4000Hz，故 `supportedRates` 不含 8000。
4. **批量档位写入**：未声明 `setStagesTxTemplate`——CompX 每档需独立地址帧，单帧模板无法表达，交由引擎按档循环写入更安全。
5. **`variables` 未声明**：引擎已原生注入 `compxDpiLow/Flags/Parity/AddrLo/AddrHi`、`stage0Parity`、`rateParity`；重复声明只会扩大求值失败面（求值异常静默返回 0）。
6. **DPI 落盘命令**：本包用 `0x08`（源码注释：`0x07` 仅拖拽预览、不持久化）。若断电后 DPI 回退，把 `setDpiValueTxTemplate` 第二个字节改回 `0x07`。
