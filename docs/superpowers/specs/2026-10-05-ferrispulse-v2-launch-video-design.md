# FerrisPulse v2.0.0 官方 4K 电影级宣传动画与无损视频导出架构设计规范

## 1. 项目愿景与目标

在完成 FerrisPulse（电量管家）从 1.0 单一雷蛇轻量工具向 2.0 全域多品牌、Win11 原生暗黑美学、全屏游戏自动调度与热更新的史诗级跨越后，打造一部**4K 广播级、高燃与致雅兼备的 JavaScript 交互式宣传发布动画**，并自动渲染导出为**极清 4K 60FPS MP4 官方宣传片**（`FerrisPulse_v2.0_Launch_4K.mp4`）。

### 双轨交付物矩阵：
1. **交互式 Web 发布会舞台 (`promo/index.html` / `showcase.html`)**：
   - 原生 4K 超清影院画幅 (3840×2160)，响应式自适应屏幕缩放，支持全屏自动巡航播放；
   - 支持自由交互把玩模式（可悬停查看各品牌卡片、点击触发水波纹与粒子）；
   - Web Audio 实时声学合成管线（复现软件内 44.1kHz 水晶八音盒音阶与电音脉冲）。
2. **确定性帧流无损 4K 视频产物 (`promo/FerrisPulse_v2.0_Launch_4K.mp4`)**：
   - 采用虚拟时钟（Virtual Clock 1/60s 帧步进）离线渲染，彻底消除实时录屏掉帧；
   - 依托本地高性能 `ffmpeg.exe`（剪映专业压制核心），生成 H.264/AAC 3840×2160@60fps 广播级 4K 成品，完美适配 B 站 4K 60FPS 极清原生角标。

## 4. 技术实现系统架构

### 4.1 前端渲染引擎 (`promo/index.html`)
- **Canvas 2D / WebGL 复合画布**：
  - 粒子系统：支持爆炸碎裂 (Shatter)、旋涡重组 (Vortex)、星尘漫浮 (Stardust)、水波纹 (Caustic Ripple) 与极光微光 Veil。
  - 摄像机控制器：支持电影级视差位移、缓动平滑推拉（Cubic Bézier）。
- **Web Audio 实时合成器 (`audio.js`)**：
  - 采用 Web Audio API 原生振荡器 (`OscillatorNode` + `GainNode` + `ConvolverNode`)；
  - 纯程序化实时合成 8 阶水晶钢片琴物理泛音、科技低音嗡鸣与空灵环境音，零外部音频资源依赖，免除跨域阻碍。
- **虚拟时钟导出挂钩**：
  - 暴露 `window.renderVideoFrame(frameIndex)` 与 `window.getVideoTotalFrames()`，供自动化离线捕获脚本调用。

### 4.2 离线帧捕获与视频压制管线 (`tools/render_promo_video.js`)
- **执行环境**：本地已安装的 `Node.js` + `Headless Chrome`（或通过 CDP 协议自动化通信）；
- **逐帧精准捕获**：
  - 以 `1/60` 秒确定性推进虚拟时间轴；
  - 每次调用截取无损 4K UHD (3840×2160) PNG 帧保存到临时缓冲区；
- **音频流渲染导出**：
  - 通过 Web Audio `OfflineAudioContext` 导出完整的 85 秒立体声 `promo_audio.wav`；
- **ffmpeg 无损压制**：
  - 调用 `E:\Program Files (x86)\JianyingPro\11.5.0.14471\ffmpeg.exe`；
  - 执行指令：
    ```cmd
    ffmpeg -y -framerate 60 -i frames/frame_%05d.png -i promo_audio.wav -c:v libx264 -pix_fmt yuv420p -crf 17 -preset slow -c:a aac -b:a 320k FerrisPulse_v2.0_Launch_4K.mp4
    ```
