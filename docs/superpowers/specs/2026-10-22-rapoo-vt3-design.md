# 雷柏 VT3 实时状态适配设计

用户已确认上一轮方案并要求开始添加设备。本设计将该方案落盘，执行方法为当前会话直接实施。

目标：移植 rapoo-tray 的雷柏状态通道，真实读取电量、充电、X/Y DPI 与档位，复用 FerrisPulse 性能控件和 OSD。
约束：C# 5.0 / .NET 4.0、Win32 P/Invoke、零外部依赖、UTF-8 BOM、保持维护头注释；工作区采用用户明确指定的 E:\code\C++\FerrisPulse，覆盖历史文档的 D 盘锚点。
方案：现有 RapooDeviceHelper 控制通道 + 独立纯协议模块 + 可取消后台状态输入；拒绝只加 PID 表（无法获得电量）和复制整个 C++ 应用（破坏现有架构）。
端点：VID 24AE，FF00/0002 输入状态，FF00/000E 输出控制，FF00/000F Feature；同一 HID 父接口分组绑定，优先完整有线端点组。键盘集合排除。
状态：0x07 报告 [2] 为零起始档位，[3..4]/[5..6] 为 X/Y DPI 小端值，[8] 为 0..100 电量，[7]/[9] 为参考充电标志。先以参考实现为依据，实际捕获报文另行标注，不把合成测试标为实测。
电量未知使用 -1；不默认满电、不吞掉真实 0/1%；无效电量保留最近有效值及时间，控制轮询不能刷新电量采样时间。USB 直连不等同充电。广播静默不能单独判定离线。
性能：寄存器控制串行，读后校验；写入不凭 Send 成功判定生效；现有 DPI 表/双轴/回报率能力需真实回读，未知回报率不伪造 1000Hz。禁止未经验证额外性能寄存器写入。
生命周期：后台 I/O 只在厂商自定义集合打开；超时取消后等待内核完成再释放事件、缓冲区和 OVERLAPPED。断开、切换与退出释放句柄，线程不访问 WinForms。
变更：RapooProtocol.cs、RapooDeviceHelper.cs / .Status.cs、DeviceManager.cs（自定义设备缓存）、MainForm.Hardware.cs（真实零电量/未知态）、tests、架构、手册与贡献说明。MIT 移植声明保留。
验证：纯解析及端点分组、Feature 布局、写入边界与无硬件拒绝；原生 build.bat、全量测试；宿主机枚举和只读实时采样。设置功能的物理效果只在实际写入并回读成功后声明。
