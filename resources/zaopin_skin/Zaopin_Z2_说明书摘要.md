## 一、指示灯定义（重点）

鼠标状态指示灯（Mouse Status Indicator）位于鼠标顶部滚轮后方。

| 灯色 | 状态 | 含义 |
| :--- | :--- | :--- |
| 红灯闪 | 闪动 | 电量过低（低电量警告），需用 USB-C 线充电 |
| 紫灯闪 | 闪动 | 充电中（charging in progress）／或鼠标处于有线模式 |
| **青灯闪** | 闪动 | **已充满电（fully charged）** |
| 蓝灯快闪 | 快闪 | 底部开关处于 BT 档，正在蓝牙配对 |
| 蓝灯常亮/停止闪 | — | 蓝牙配对成功 |

> ⚠️ **版本差异**：MECHKEYS 版说明书写作「充满时指示灯熄灭（power indicator shall turn off when it is full）」，
> 与新版「青灯闪 = 充满」矛盾。可能是不同批次固件行为差异，以扫码看实际灯色为准。

## 二、三模连接

### 2.4G 无线
- 接收器与鼠标出厂已配对，即插即用。
- 底部开关拨到 **2.4G** 档即可。
- 4K 版配备 4K 接收器（无 1K 接收器；1K 需在驱动内切换）。

### 蓝牙（BT）
1. 底部开关拨到 **BT** 档。
2. 同时按住 **左键 + 中键（滚轮按下）+ 右键** 约 3 秒。
3. 指示灯蓝灯快闪 → 进入配对模式。
4. 电脑蓝牙列表搜索 **「zaopinZ2」** 并连接。
5. 配对成功蓝灯停止闪烁。

### 有线 USB-C
- 用附带的 USB-C 线直连电脑，即进入有线模式并同时充电。

## 七、常见问题（官方 Troubleshooting）

### 1. 光标偶尔闪烁、卡顿
- 检查驱动内 **LOD（静默高度）** 是否为 **1mm**；大于 1mm 会异常。
- 数据线接主板 USB 口，不要接机箱前面板。

### 2. 右键断连 / 按下后不回弹
- 可拆底部螺丝调整微动位置。

### 3. 通用排查步骤
1. 确认鼠标底盖**没有额外叠加脚贴**（关键）。
2. 确认底部开关已拨到 **ON**（非 OFF）。
3. 无线模式下确认接收器已连接、且**靠近鼠标**。
4. 驱动首页右下角点击 **「Restore Defaults」** 恢复默认。

## 八、与 FerrisPulse 适配的关联说明

| 项 | 说明 |
| :--- | :--- |
| 充满判断 | 软件读 `rxBat[7]` 仅能区分「充电中／未充电」，**无法感知 LED 颜色**。若要标「已充满」，只能以「电量 100% + 充电中」推断 |
| 低电量提醒 | 官方以红灯闪表示低电量，可作为软件低电量阈值（默认 20%）的参考 |
| 充电中 | 官方以紫灯闪表示，与协议 `rxBat[7]==1` 语义一致 |
| 有线模式 | 紫灯闪亦表示有线模式，故软件显示「⚡ USB 充电中」符合官方行为 |
